# IELTS Prep

Бесплатный сайт для подготовки к IELTS. Работает без сервера и сборки: просто откройте `index.html` в браузере.

## Разделы

- **Reading**: академические тексты с вопросами TRUE/FALSE/NOT GIVEN, YES/NO/NOT GIVEN, поиском абзаца, выбором ответа и пропусками. Есть таймер, автопроверка и примерный band.
- **Listening**: диалог (Section 1) и монолог (Section 2) озвучиваются синтезатором речи браузера. Можно включить режим «только один раз», транскрипт показывается после проверки.
- **Writing**: задания Task 1 и Task 2 с таймером (20/40 мин) и счётчиком слов. Черновики сохраняются автоматически, есть чек-лист по критериям оценки и полезные фразы.
- **Speaking**: вопросы Part 1, карточки Part 2 с таймером 1+2 минуты, вопросы Part 3, запись своего ответа с микрофона.
- **Тренажёр слов**: больше 200 слов по темам Education, Technology, Environment, Health, Work, Travel, Society и Academic, у каждого слова транскрипция, перевод и пример. Карточки «Знаю / Не знаю» с интервальным повторением: незнакомые слова показываются чаще. Есть тест с выбором из 4 вариантов, прогресс по каждой теме и можно добавлять свои слова.
- **Калькулятор**: перевод сырых баллов в band и расчёт Overall.

Прогресс хранится в `localStorage` браузера. Есть светлая и тёмная тема, переключатель находится в шапке.

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → выберите ветку и папку `/ (root)`.

## Как добавить материалы

Тексты, вопросы и темы для Writing и Speaking лежат в `js/data.js`. Чтобы добавить новый тест, допишите объект в массив `READING` или `LISTENING` по образцу существующих.

Слова лежат в `js/words.js`. Каждое слово записывается так: `["слово", "/транскрипция/", "перевод", "пример"]`. Новую тему можно добавить как ещё один объект в массив `WORD_TOPICS`.
