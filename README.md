# IELTS Prep

Бесплатный сайт для подготовки к IELTS. Работает без сервера и сборки, на чистом HTML, CSS и JavaScript. Лучше открывать через GitHub Pages или любой локальный сервер. Если открыть `index.html` прямо из папки, сайт тоже работает.

## Разделы

- **Reading**: академические тексты с вопросами TRUE/FALSE/NOT GIVEN, YES/NO/NOT GIVEN, поиском абзаца, выбором ответа и пропусками. Есть таймер, автопроверка и примерный band.
- **Listening**: 4 части и 40 вопросов, от бытового диалога до академической лекции. Типы вопросов: заполнение формы, выбор ответа, matching и заметки. Текст озвучивает синтезатор речи браузера (Web Speech API). По возможности выбирается британский голос, у каждого говорящего свой голос.
  - «Экзамен»: запись звучит один раз, без паузы и перемотки. Перед каждой частью 30 секунд на чтение вопросов, между частями пауза. В конце показывается результат и band.
  - «Тренировка»: пауза, переход по репликам, выбор скорости. После проверки ответов открывается текст записи, по нему можно слушать с любой реплики.
- **Writing**: задания Task 1 и Task 2 с таймером (20/40 мин) и счётчиком слов. Черновики сохраняются автоматически, есть чек-лист по критериям оценки и полезные фразы.
- **Speaking**: вопросы Part 1, карточки Part 2 с таймером 1+2 минуты, вопросы Part 3, запись своего ответа с микрофона.
- **Тренажёр слов**: больше 200 слов по темам Education, Technology, Environment, Health, Work, Travel, Society и Academic, у каждого слова транскрипция, перевод и пример.
  - Карточки «Знаю / Не знаю» с интервальным повторением. Горячие клавиши: пробел переворачивает, ← и → отвечают.
  - Тест с выбором из 4 вариантов, прогресс по каждой теме.
  - «Мои слова»: можно добавить слово вручную или импортировать сразу тысячи слов из текста или файла .txt/.csv (форматы `word - перевод`, `word;перевод;пример`, через Tab из Excel). Перед сохранением показывается превью с дублями и ошибками. Есть экспорт в CSV для резервной копии.
- **Калькулятор**: перевод сырых баллов в band и расчёт Overall.

Прогресс хранится в `localStorage` браузера. Есть светлая и тёмная тема, переключатель находится в шапке.

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → выберите ветку и папку `/ (root)`.

## Как устроен код

- `index.html` загружает только стили и `js/core.js`.
- `js/core.js`: общие функции, хранилище (пишет в `localStorage` пачками), роутер, тема, меню, выбор голосов. Код раздела подгружается, только когда раздел открывают.
- `js/pages/*.js`: по файлу на раздел. `vocab-mine.js` (импорт слов) грузится только при открытии вкладки «Мои слова».
- `js/data/*.js`: учебные материалы.
- `js/vocab-core.js`: темы, свои слова и интервальное повторение (нужен словарю и главной).

## Как добавить материалы

- Тексты для Reading лежат в `js/data/reading.js`, части Listening в `js/data/listening.js`, задания Writing и Speaking в `js/data/writing.js` и `js/data/speaking.js`. Новый тест добавляется объектом по образцу существующих.
- Слова лежат в `js/data/words.js`. Каждое слово записывается так: `["слово", "/транскрипция/", "перевод", "пример"]`. Новую тему можно добавить как ещё один объект в массив `WORD_TOPICS`.
- После изменения файлов увеличьте `VERSION` в `js/core.js` и `?v=` в `index.html`, чтобы браузеры не показывали старую версию из кэша.
